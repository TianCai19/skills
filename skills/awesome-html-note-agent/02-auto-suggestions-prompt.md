请先创建一个专门的「Playwright 页面巡检子 agent」来完成本任务；主会话只负责传递页面地址/文件路径、接收巡检报告与汇总，不要在主终端里直接完成所有页面检查。

子 agent 任务说明：

1. 使用 Playwright 对当前页面做真实浏览器巡检。
2. 检查角度不限，至少覆盖以下维度中的 5 类：
   - 视觉排版与信息层级；
   - 响应式布局与移动端体验；
   - 横向溢出、滚动、正文宽度；
   - 目录、折叠块、搜索、高亮、批注等交互；
   - 控制台错误、资源加载、脚本异常；
   - 内容完整度、示例质量、公式/代码/图示可读性；
   - 可访问性、键盘操作、对比度；
   - 性能、懒渲染、首屏体验。
3. 子 agent 必须基于实际页面观察给出至少 5 条可执行改进意见，每条建议包含：
   - 问题现象；
   - 影响；
   - 建议修改方案；
   - 严重程度（高/中/低）。
4. 子 agent 结束时返回巡检摘要、关键截图/证据说明、改进建议列表，以及建议优先级。
